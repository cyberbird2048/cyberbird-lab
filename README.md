# cyberbird-lab

> cyber bird 的对外分享项目合集 · **open builds in public**
>
> 我在公众号写"做了个东西送你"的时候，对应的开源实现都放在这里。
> 每篇文章结尾那句"这套我可以拆给你"，指向下面某个目录——说的和做的一致。

## 项目

| 目录 | 干什么 | 对应文章 |
|------|--------|---------|
| [`wechat-data-loop/`](./wechat-data-loop) | 公众号数据自动回收回路：发完文章自动抓阅读/分享/阅读时长，算分享率，归因"哪类内容真正管用"，喂给下一篇选题 | 《写了 18 篇文章，我第一次看了它们的数据》 |

_持续更新。每做一个值得分享的东西，就加一个目录进来。_

## 为什么是合集而不是多个 repo

我不想让每个小项目各自冷启动、各自掉粉。这里是一个**作品集入口**——
你来一次，能看到我做过的所有东西；我每次分享，只需要指回这一个地址。
